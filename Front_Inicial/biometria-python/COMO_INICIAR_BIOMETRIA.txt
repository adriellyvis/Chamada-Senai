PreZence - serviço Python de biometria

Para desenvolvimento local:

INICIAR_BIOMETRIA_LOCAL.bat

ou:

py app.py

A comunicação interna Spring -> Python usa BIOMETRIA_SERVICE_KEY.
O código possui o fallback de desenvolvimento "prezence-dev-2026", alinhado com o backend.
Em deploy/produção, configure BIOMETRIA_SERVICE_KEY como variável de ambiente com uma chave própria e segura.

Nunca coloque a chave interna no JavaScript do navegador.
Nunca versione fotos, amostras faciais ou arquivos gerados em dados_biometricos/.
